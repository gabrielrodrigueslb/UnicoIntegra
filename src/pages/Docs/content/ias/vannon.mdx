# Criar IA Vannon

Cria uma IA voltada para fluxo de e-commerce com busca de produtos, pré-processamento e contexto por loja.

<MethodBadge method="POST" path="/api/ia/create-ai/vannon" />

<Callout type="warning" title="Endpoint do cliente">
  Use o endpoint público da loja. O backend extrai o domínio base desse valor para preencher
  as variáveis do template.
</Callout>

## Autenticação

O backend autentica diretamente na instância usando `username`, `password` e `code`.
Quando a criação parte do painel, esses campos são preenchidos pela sessão atual.

Veja também: <Link to="/main/docs/getting-started/autenticacao">Autenticação</Link>

## Headers

| Header | Valor |
| --- | --- |
| `Content-Type` | `application/json` |

## Body

<ParamsTable params={bodyParams} />

## Fluxo interno

- Autentica na instância.
- Cria um assistente base.
- Instala download de imagens, busca de produtos, pré-processamento, URA principal e URA AB.
- Atualiza o assistente com o template final da IA Vannon.

## Exemplo de requisição

<CodeBlock language="json">{`{
  "instance": "https://cliente.exemplo.com",
  "username": "operacao@cliente.com",
  "password": "senha-da-instancia",
  "code": "123456",
  "name": "IA - Vannon Loja Centro",
  "clientName": "Farmácia Centro",
  "apiKey": "vannon-api-key",
  "clientEndpoint": "https://farmaciacentro.vannon.app",
  "cepLoja": 30140071
}`}</CodeBlock>

<CodeBlock language="json">{`{
