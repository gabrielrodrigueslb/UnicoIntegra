# IA Vetor

Esta página deve ser lida como **procedimento de implantação** da Vetor.
O foco aqui é operacional: solicitar as credenciais, validar internamente, instalar a IA e homologar.

<Callout type="info" title="Primeiro passo">
  Assim que o cliente chegar, a solicitação das credenciais da Vetor deve ser feita diretamente
  no grupo do WhatsApp. Depois disso, confirme com Maicon ou Moara antes de prosseguir com os dados do cliente.
</Callout>

## Visão geral do processo

1. Solicitar as credenciais da Vetor no grupo do WhatsApp.
2. Validar com Maicon ou Moara antes de seguir com os dados do cliente.
3. Receber os dados necessários para a instalação.
4. Acessar o módulo de IAs e configurar a IA Vetor.
5. Verificar se a fila possui a API key correta.
6. Homologar antes de liberar em produção.

## Passo 1: Solicitar as credenciais

Assim que o cliente chegar, solicite as credenciais da Vetor diretamente no grupo do WhatsApp.

Esse é o ponto de partida da implantação. Sem o token enviado pela Vetor, a configuração da IA não deve começar.

## Passo 2: Validar internamente

Quando a solicitação for feita, confirme com **Maicon** ou **Moara** antes de prosseguir com a
solicitação dos dados do cliente.

Essa validação deve acontecer antes da instalação, para garantir que o processo está liberado para seguir.

## Passo 3: Instalar a IA Vetor

Depois de receber os dados, vá diretamente para a **sexta opção da barra lateral do sistema**,
na área de **IAs**, e entre em **Configurar IA Vetor**.

Preencha os campos da instalação:

<ParamsTable params={installParams} />

Esses dados são os que autorizam a criação da IA na instância do cliente.

<Callout type="warning" title="Ponto de atenção">
  O token enviado pela Vetor é obrigatório. Sem ele, a instalação não deve prosseguir.
</Callout>

## Passo 4: Verificar a API key da fila

Antes de vincular a IA a uma fila de atendimento, confira se a fila tem uma API key definida.

Essa API key precisa estar alinhada com a API key global informada na instalação.
Se a fila estiver sem essa chave, a integração não vai funcionar.

<Callout type="warning" title="Validação obrigatória">
  Se a fila não tiver API key, ou se a chave estiver diferente da API key global usada na instalação,
  a IA não vai funcionar corretamente no atendimento.
</Callout>

## Passo 5: Homologação inicial

Após a instalação:

- configure a URAB inicialmente para transferir apenas para a loja e para você
- rode a validação e homologação junto com o cliente
- confirme se a IA está respondendo bem
- só depois direcione definitivamente para o cliente

Essa etapa é obrigatória antes de liberar o fluxo em produção.
