# Criar IA Vetor

Cria uma IA integrada ao fluxo Vetor com token dedicado, busca de produtos e automações auxiliares.

<MethodBadge method="POST" path="/api/ia/create-ai/vetor" />

<Callout type="warning" title="Mensagem atual de validação">
  Se <code>vetorToken</code> não for enviado, a controller atual responde com uma mensagem
  incorreta para <code>clientEndpoint</code>. O campo exigido de fato é <code>vetorToken</code>.
</Callout>

## Autenticação

O backend autentica diretamente na instância usando `username`, `password` e `code`.
Quando a criação acontece pelo painel, esses valores são preenchidos automaticamente pela sessão.

Veja também: <Link to="/main/docs/getting-started/autenticacao">Autenticação</Link>

## Headers

| Header | Valor |
| --- | --- |
| `Content-Type` | `application/json` |

## Body

<ParamsTable params={bodyParams} />

## Fluxo interno

- Autentica na instância.
- Cria um assistente base.
- Instala download de imagens, busca de produtos, pré-processamento, URA principal e URA AB.
- Atualiza o assistente com o template final da IA Vetor.

## Exemplo de requisição

<CodeBlock language="json">{`{

  "vetorToken": "AgAAAGmNu9AtfU9..."
